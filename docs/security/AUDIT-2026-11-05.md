# Read-path audit, 2026-11-05

Audit base: `2f0775f3a11d` (`sprint/serialize-audit`), format 2.0, pinned
Squirrel 3.2 sq64 with SQUSEDOUBLE. The table was written before source changes.
Bounds below assume the declared public holder/blob shapes and no concurrent
mutation of the input blob or internal stream fields. Wire bytes, lengths and
field values are untrusted; declarations, holders, callbacks and reset are
supplied by the caller. A caller can deliberately violate those assumptions;
that is distinguished from an input-only path in the findings.

## Findings

### sra-nut-1 — incomplete integer declaration validation

- Location: `src/serialize_int.nut:100,147`,
  `src/serialize_int128.nut:201`, `src/serialize_fixed.nut:102-109,123-129`.
- Effect: caller-supplied fractional/equal bounds can be accepted as a zero-bit
  integer; other malformed bound types reach throwing arithmetic/indexing.
  Extreme caller Q widths reach addition before the width sum is bounded.
  Packet bytes alone do not choose these declarations or carrier shapes.
- Severity: **low**; U7/U16 refusal contract and integration hardening, without
  a demonstrated bytes-only denial of service on a valid declaration.
- Reduction: validate integer types/carrier shape and individual Q widths before
  arithmetic, using the existing `value_out_of_range` refusal. Preserve valid
  declarations, first reason, holder and bit count on the rejected call.
- Status: **fixed**, commit `98b00ceb331d2a105d43404d8c3120be12bbcf54`.
  The change adds only pre-arithmetic declaration guards in three source files;
  no cursor update, group assembly, allocation, or latch algorithm changes.
- Pin: `test/uniform/uniform_test.nut:477-496`:
  `TestReadIntegerDeclarationAuditInt32`, `Int64`, `Int128`, `Fixed64`,
  `Fixed128`, `TestReadFixed64WidthAudit`, `TestReadFixed128WidthAudit`.
  `fuzz/differential_test.go:1675,1706` adds
  `TestReadIntegerDeclarationSeeds` (2,640 cases, seed `0x20261105`) and
  `FuzzReadIntegerDeclarations` (eight retained seeds), through the existing
  `fuzz/driver.nut:379` driver. These pin a refusal before output/index change,
  both when healthy and when already refused.
- Before: the same new family tests against the unchanged base source all fail;
  the width tests also fail under UBSan. Representative red lines:

  ```text
  AN ERROR HAS OCCURRED [uniform: int min float: read raised bitwise op between 'float' and 'integer']
  --- FAIL TestReadIntegerDeclarationAuditInt32 (test/uniform/uniform_test.nut: exit 0)
  --- FAIL TestReadIntegerDeclarationAuditInt64 (test/uniform/uniform_test.nut: exit 0)
  --- FAIL TestReadIntegerDeclarationAuditInt128 (test/uniform/uniform_test.nut: exit 0)
  --- FAIL TestReadIntegerDeclarationAuditFixed64 (test/uniform/uniform_test.nut: exit 0)

  --- FAIL TestReadFixed64WidthAudit (test/uniform/uniform_test.nut: exit 1)
  ```

  The new fuzz seed test is also red on the base: `AN ERROR HAS OCCURRED

  After: all seven new named unit tests, the deterministic seed matrix, and
  the native fuzz target pass. No new test file or public API is introduced.

### sra-nut-2 — malformed caller objects/holders are outside the checked boundary

- Location: `src/serialize_stream.nut:283,321`,
  `src/serialize_bits.nut:188,198,205,211,216,221,226`, and scalar holder
  assignments in the other read families.
- Effect: non-blob initialization, an object without a callable serializer, or
  a malformed scalar holder can throw. A holder failure can occur after bytes
  have moved. These are caller-created Squirrel values, not values created by
  the packet decoder. The documented holder shape works and refused wire
  values do not write it.
- Severity: **info**; no direct untrusted-byte reachability established.
- Reduction: a separate API-contract pass can define whether every malformed
  holder/callback shape must be refused and how initialization reports an error;
  do not add catch-all handling around arbitrary caller callback exceptions.
- Pin: existing `TestU7ReadNeverTraps` covers declared malformed string holders
  and bytes destinations, but not the wider object/holder matrix. **Open**, no
  runtime fix or broadened guarantee claimed here.
- PATHS-PROPOSED: `DESIGN.md`, `src/serialize_stream.nut`, `src/serialize_bits.nut`,
  `src/serialize_int.nut`, `src/serialize_int128.nut`, `src/serialize_fixed.nut`,
  `src/serialize_float.nut`, `src/serialize_compressed_float.nut`,
  `src/serialize_int_relative.nut`, `test/uniform/uniform_test.nut`, `fuzz/**`.

### sra-nut-3 — compressed-float declaration tolerance remains

- Location: `src/serialize_compressed_float.nut:51-72,137-151,167-170`.
- Effect: the read declaration path intentionally omits the strict finite
  delta/quotient check used by the writer. Non-numeric caller parameters can
  reach `fround` before a refusal or terminal-state check. Raw integer bytes
  still face the integer bound and finite-result check, so no NaN/infinity can
  be returned by a successful read with well-formed numeric parameters.
- Severity: **low**, caller-declaration contract; no valid-declaration,
  bytes-only bypass established.
- Reduction: reconcile this documented read tolerance with the in-flight
  strict-declaration policy, then validate caller numeric types before float
  helpers. Do not independently redefine the strict-only work here.
- Pin: current conformance compressed-float range/non-finite-decode controls
  and uniform precomputed-constant tests remain; broader malformed-declaration
  matrix is **open**, not a completed fix.
- PATHS-PROPOSED: `DESIGN.md`, `src/serialize_compressed_float.nut`,
  `test/compressed_float/compressed_float_test.nut`,
  `test/uniform/uniform_test.nut`, `fuzz/**`.

## Failure and resource observations

The first reason is terminal for all valid public read declarations. A scalar
wire refusal keeps the holder unchanged. `serializeBytes` checks alignment and
whole room before touching its destination; `serializeString` stages into a
private blob, validates, then assigns. A composite object's earlier successful
fields remain visible on later failure, as STANDARD.md permits; callers must
not use a refused message. A failed primitive's bit position is not rolled
back and must not be interpreted as a resumable cursor.

Lengths and data-dependent work are bounded by the input blob and caller
schema size. Strings cannot allocate their claimed payload before it fits the
remaining bytes. They can still copy a large valid payload; packet and
application quotas belong at the boundary, not in a new runtime option.
The library adds no data-controlled callback recursion. No JSON parser,
network access, or data-selected module path exists on the production read
path. Loader filenames come from fixed dispatch names.

The raw `BitReader` is an exported trusted primitive, with a throwing contract
and no refusal reason/latch; the checked `ReadStream` validates before reaching
it. Its raw method names are not evidence that it has the checked stream's
contract. Input blob mutation, internal-field tampering and caller callbacks
are not attacker-byte capabilities established by this audit.

Reproduction: extract the base's `src/` at `2f0775f3a11d` into
`build/audit/base/`, keep the fixed tree's `src/`, and run the following

```squirrel
local root = vargv[0];
local baseline = dofile(root + "/build/audit/base/src/serialize.nut", true);
local after = dofile(root + "/src/serialize.nut", true);
local makeRead = function(api, family) {
  local wire = blob(64);
  local rs = api.ReadStream(wire);
  local h = { value = 0 };
  local lo = [0, 0], hi = [0, 1];
  return function(n) {
    for (local i = 0; i < n; i++) {
      rs.reset(wire);
      local ok;
      if (family == 0) ok = rs.serializeInt(h, -100, 100);
      else if (family == 1) ok = rs.serializeInt64(h, -0x10000000000, 0x10000000000);
      else if (family == 2) ok = rs.serializeInt128(h, lo, hi);
      else if (family == 3) ok = rs.serializeFixed64(h, 32, 32, -100, 100);
      else ok = rs.serializeFixed128(h, 64, 64, -100, 100);
      if (!ok) throw "benchmark read refused";
    }
  };
};
local n = 100000;
for (local family = 0; family < 5; family++) {
  local beforeRead = makeRead(baseline, family);
  local afterRead = makeRead(after, family);
  beforeRead(1000); afterRead(1000);
  for (local pair = 0; pair < 7; pair++) {
    local b, a, start;
    if (pair % 2 == 0) {
      start = clock(); beforeRead(n); b = clock() - start;
      start = clock(); afterRead(n); a = clock() - start;
    } else {
      start = clock(); afterRead(n); a = clock() - start;
      start = clock(); beforeRead(n); b = clock() - start;
    }
    print(format("%d %d %.9f %.9f\n", family, pair, b * 1e9 / n, a * 1e9 / n));
  }
}
print("paired-cpu-pass\n");
```


### Limits and work left open

- This is a source audit plus finite tests and bounded fuzzing, not a proof over
  all byte strings, embedding configurations, allocations or races.
- Findings `sra-nut-2` and `sra-nut-3` remain open with their proposed paths.
  Their broader malformed-caller matrices were not added to the fuzz target;
  the current target covers the fixed integer declaration boundary. The
  existing differential still mutates valid programs' packet bytes across
  every supported operation.
- The strict-only compressed-float policy was not redone. Raw `BitReader`'s
  documented contract was not changed. No runtime quota, new public API,
  catch-all callback handling, or broad refactor was added.
- No state/index algorithm changed. TLA+ was not run or claimed for these pure
  declaration guards. The upstream model linked by IMPLEMENTING.md is not
  present here; a future state/index fix must include the actual model and a
  reversed witness under appropriate path scope.
- Non-Linux platform gates and unbounded/nightly fuzz runs were not run.
  The read-path conclusions assume the pinned VM and valid caller-owned
  holders, buffers and callbacks as distinguished above.
